# OpenSTA SKY130 Codespace

A browser-based OpenSTA and SKY130 PDK environment for static timing analysis.

## Included

- OpenSTA
- SKY130A PDK
- `sky130_fd_sc_hd` standard-cell library
- Yosys
- Icarus Verilog
- GTKWave
- XFCE desktop
- noVNC browser access

1. Open the repository on GitHub.
2. Select:
