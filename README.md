# vsd-opensta

# OpenSTA Static Timing Analysis on Cloud

This repository provides a ready-to-use GitHub Codespace for OpenSTA, following the same browser-based setup used by `vsdip/vsd-rtl`.

## Included Tools

- OpenSTA
- CUDD 3.0.0
- CMake
- SWIG
- Flex
- Bison
- Eigen
- Tcl
- fmt
- Yosys
- Icarus Verilog
- GTKWave
- XFCE desktop
- noVNC browser desktop
